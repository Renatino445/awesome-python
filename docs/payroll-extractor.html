Estrattore Dati da Buste Paga PDF

Carica una busta paga in formato PDF, nativa o scannerizzata: il sistema utilizza PDF.js per i documenti testuali e Tesseract.js per l'OCR delle scansioni. I dati chiave rilevati (Nome, Codice Fiscale, Netto da Pagare, Periodo) saranno estratti automaticamente.

  1. Seleziona o trascina un file PDF nell'area tratteggiata.
  2. Attendi che l'elaborazione e l'OCR si concludano: lo stato di avanzamento compare in alto.
  3. Consulta i campi popolati nella sezione Dati Estratti e verifica il testo completo, se necessario.
  4. Ripeti l'operazione con un nuovo file oppure chiudi la pagina quando hai terminato.
